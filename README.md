# Каталог фильмов (Movie Catalog)

## Краткое описание приложения
Приложение позволяет пользователю вести личный каталог просмотренных или желаемых к просмотру фильмов и сериалов. Пользователь может добавлять новые записи, указывая название, жанр, год выпуска, рейтинг и описание, а также просматривать, редактировать и удалять существующие записи.

## Основные функции
1. Просмотр списка всех добавленных фильмов на главном экране.
2. Добавление нового фильма с проверкой обязательного поля "Название".
3. Просмотр подробной информации о фильме на отдельном экране.
4. Редактирование данных существующей записи.
5. Удаление записи с подтверждением действия через диалоговое окно.
6. Сохранение данных локально на устройстве (данные не теряются после перезапуска приложения).

## Используемые технологии
- Язык программирования: **Java**
- Разметка интерфейса: **XML**
- Компоненты UI: **Activity**, **RecyclerView**, **CardView**, **Material Components**
- Среда разработки: **Android Studio**

## Способ хранения данных
- **SQLite** (локальная база данных на устройстве). Реализован класс `MovieDatabaseHelper`, наследующий `SQLiteOpenHelper`, который управляет созданием таблицы и операциями CRUD (Create, Read, Update, Delete).

## Инструкция по запуску
1. Откройте проект в Android Studio.
2. Дождитесь завершения синхронизации Gradle.
3. Выберите эмулятор или подключите реальное Android-устройство.
4. Нажмите кнопку **Run** (зеленый треугольник) или `Shift + F10`.
5. Приложение запустится на главном экране со списком фильмов.

## Структура проекта
- `Movie.java` – модель данных (POJO-класс).
- `MovieDatabaseHelper.java` – класс для работы с SQLite (создание БД, CRUD-операции).
- `MovieAdapter.java` – адаптер для отображения списка в RecyclerView.
- `MainActivity.java` – главный экран со списком.
- `AddEditMovieActivity.java` – экран добавления и редактирования записи.
- `MovieDetailActivity.java` – экран просмотра деталей записи.
- `res/layout/*.xml` – файлы разметки интерфейса.

## Что реализовано
- Полностью реализованы все требования задания: 3 экрана, навигация, CRUD-операции, валидация пустого поля "Название", сохранение данных в SQLite.
